# Terminal Task Runner

Use when hosting long commands, builds, tests, SSH sessions, or REPLs.

## Essentials

- Use `run-background.sh` for long-running terminal work.
- Use `capture-screen.sh` to inspect output.
- Use `send-to-session.sh` to intervene.
- On Windows/WezTerm, do not assume the pane shell. Probe with a harmless command before sending shell-specific syntax.
